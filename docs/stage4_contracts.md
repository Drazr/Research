A decoder route is one frozen source-language head applied to one target-language view at the **same** model, input condition, site and depth. Each model has two conditions (`image_caption`, `caption_only`), two poolings (`last_caption`, `caption_mean`), four physical depths and sixteen directed language routes including diagonals. Qwen depths are 9/18/27/36 and Gemma depths are 9/17/26/34. Resolve from the accepted inventory and fail on a mismatch. Each image-only encoder/projector block has one row per image and no language axis. E03 has separate word TF-IDF, character TF-IDF and length readouts per language. Its pooled character block has four views per image, reported by context and equally averaged across contexts. Distinct vocabularies never enter a coefficient-transfer grid.

Apply the **source** Stage 3 transform unchanged, then evaluate the saved coefficient matrix and intercept in float64. Match Stage 3 dense centering, sparse uncentered TF-IDF and scale-floor semantics. Preserve the estimability flags and exclude padding for a non-estimable head. Derive `p=sigmoid(logit)` with a stable sigmoid, `d=1[p>=0.5]`, and the separate correctness-confidence event where required. Persist canonical logits once. Derive probabilities and decisions from those logits with one shared implementation. Source-FIT prevalence is known-cell weighted prevalence from that system's FIT population and is held fixed when applied to other contexts. The always-absent reference predicts zero. The probability reference uses the FIT prevalence.

Use a Stage 4 authorization layer around the Stage 3 plan and Stage 2 numeric verification logic. Keep Stage 3 role guards and numerical identity intact. In a scoring session, reuse each target feature matrix across the four source heads and reuse selected weights and scaler within their ownership block. Keep memory bounded. Cross-model raw coordinates never mix.

## Analysis contracts

**E01 — accessibility and transfer.** Use the `image_caption`/`last_caption` grid at all four fixed depths. Report the four diagonals and twelve directed transfers per depth and model. Per category, report AUROC, average precision, Brier, binary NLL, sensitivity, specificity, F1 and balanced accuracy, along with support and the fixed FIT-prior/always-absent references. For NLL only, clip probabilities to `[1e-15, 1-1e-15]` in float64. Use standard tied ranks for AUROC and step-based average precision. Preserve absolute results and diagonal-minus-transfer discrimination gaps on identical target cells. For loss use transfer minus matched diagonal. Report all fixed depths. Selecting a layer would activate the E16 supervision/reporting guard and is outside this execution block.

**E02 — input evidence.** Compare combined versus caption-only `last_caption` results on the same model, depth, source, target and image-category cohort, including the change in transfer gap. Report both underlying absolute scores and paired differences. Display image-only encoder and projector baselines separately, once per physical site and model, with paired image-level comparisons where defined. A visual reference stays a single shared observation. The condition contrast is an observational diagnostic under changed inputs.

**E03 — shallow caption references.** Score the 12 language-specific systems and pooled character readout once. Report each recipe per language and the equally weighted pooled-context macro. Pair each shallow context with the corresponding same-context neural caption-only midpoint `last_caption` result, separately by model. Retain absolute scores, support and paired deltas so readers can distinguish performance and coverage. E03 is a single shared result in the Stage 5 handoff.

**E04 — pooling sensitivity.** For each model and fixed depth, compare `last_caption` and `caption_mean` on the complete matched combined-input route grid. Also release the corresponding caption-only grid as a condition-specific diagnostic. Document both unsupported optional readout arms, `post_caption` and decoder visual-token pooling. Encoder/projector image-only references belong to E02. Report all grids and paired differences with support, alongside the existing token/site evidence. Preserve fixed selection and visibility constraints.

**E19 — source confidence.** At each model's E01 midpoint (Qwen 18, Gemma 17), compute `c=max(p,1-p)` per category and source. For each nominal coverage `q` in 0.50/0.75/0.90, set the source-DEV-C cutoff to the `ceil(q*n)`-th largest score among that head's scoreable source rows. Retain all scores `c>=cutoff`, including ties. DEV-C confidence alone sets the cutoff; SCREEN outcomes only evaluate it. Evaluate all 16 routes on SCREEN. Report actual source and target coverage, retained errors/risk, base error/prevalence, AUROC/AP and the score-blind expected risk at actual matched coverage. Break out positive/negative retention, sensitivity/specificity among retained cases and overall retained correct rates within each class. Report the raw counts and correctness support as well as fixed-cohort summaries. The diagonal uses the same source policy. Keep fitted cutoffs fixed throughout SCREEN inference and resampling. Evaluate the declared constant references under the same tie rule and display their actual coverage.

**E25 — paired errors.** At the same E01 midpoint, compare all six unordered target-context pairs for each of the four fixed source heads. Also report the six pairs between language-specific diagonal heads as the secondary comparison. Use shared known cells to measure decision disagreement and common-wrong events. Compute conditional outcomes within true `y=0` and `y=1`. Report marginal errors, joint errors, the product-of-marginals reference, excess joint errors, and both directional conditional error rates with their denominators. Use the same 0.5 rule throughout. As a descriptive association diagnostic, shuffle the second error vector within each category's true-label stratum 1,000 times while preserving its counts. Report empirical null quantiles alongside the observed overlap and paired bootstrap. Label the score-blind independence reference separately from the fixed prevalence and always-absent classifiers. Preserve sparse, constant or unresolved strata in the tables with explicit support and status.

## Support, uncertainty and reproducibility

- Distinguish an unsupported/undefined metric from a finite low-support descriptive estimate. Release support counts in all 25 categories. Apply the frozen split support rules and the additional minimum of 20 per relevant outcome class for inferential subgroup/correctness summaries. Report zero denominators as undefined. A primary macro uses exactly the 14 frozen categories. When one is undefined, mark that macro unresolved and report a separately identified matched eligible cohort when useful, with its membership and support. Apply the same mask and denominator rules to both arms before computing paired differences. Report rates as fractions with their denominator counts.
- Draw 2,000 shared SCREEN bootstrap samples of 360 image IDs with replacement, retaining all compared language views, labels and masks for each image occurrence. Use one common draw matrix for the full study, including both models and E03. Calculate paired differences within the same draw and report percentile 95% intervals plus valid/total draw counts. Use linear quantile interpolation for these intervals and E25's descriptive 2.5th/97.5th null percentiles. An undefined draw is excluded with its status recorded. A primary macro draw requires all fixed primary terms. These intervals are exploratory and conditional on the frozen fits, and on frozen DEV-C cutoffs for E19. Retain point estimates, sample support and intervals for paired outcomes.
- Freeze the bootstrap generator as NumPy `Generator(PCG64(2026111804))` on the sorted SCREEN image IDs with `integers(0,360,size=(2000,360),dtype=int64)`; retain the realized matrix and software version. For E25 use independent deterministic streams keyed by SHA-256 of `G9Q6-E25-association-v1|CATEGORY_ID|LABEL`, first eight bytes big-endian as the PCG64 seed, and generate permutations of each sorted stratum's image positions. Share those maps for all comparisons on the exact same stratum membership. Any missing comparison rows block the primary inventory; a documented descriptive subset would need its own keyed membership. Publish map recipe and membership hashes. A small independent fixture must reproduce both resampling schemes and pair alignment. These operational seeds are separate from Stage 3 G0.
- Use explicit status values `ok`, `descriptive_low_support`, `undefined`, `unavailable`, and `blocked` with reasons. Undefined includes metric mathematics or inadequate support for the requested inferential summary. Unavailable identifies an unscheduled or technically unsupported optional arm. Missing scheduled artifacts, wrong row sets, unexpected missing primary support or broken integrity block acceptance. Keep denominator, paired cohort and supervision labels in machine-readable results. The initial screen supplies exploratory patterns within released caption contexts. It cannot isolate language alone, establish caption meaning equivalence or attribute model decisions to a causal mechanism.
